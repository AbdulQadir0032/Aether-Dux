# Aether-Dux
Aether Dux — a futuristic, responsive multi-page website for an autonomous aerial technology company focused on autonomous flight systems, precision delivery, custom drone engineering, and emergency response solutions. Built with HTML5, Tailwind CSS, and vanilla JavaScript.
# Aether Dux 🚁

### Aerial Technology. Limitless Possibilities.

Aether Dux is a futuristic autonomous aerial technology company focused on developing intelligent flight systems for **emergency response, precision delivery, and custom drone engineering**.

This repository contains the official Aether Dux corporate website, designed with a premium aerospace and defense-technology aesthetic while incorporating subtle Nigerian-inspired visual elements.

---

## 🌍 About Aether Dux

Aether Dux explores the intersection of:

* Autonomous flight
* Artificial intelligence
* Drone engineering
* Aerial logistics
* Emergency response
* Precision delivery
* Robotics
* Mission-critical technology

Our vision is to create aerial systems that make distance less of a barrier — enabling critical payloads, intelligence, and services to reach places where conventional infrastructure may be limited.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/aether-dux-website.git
```

### 2. Enter the project directory

```bash
cd aether-dux-website
```

### 3. Open the website

Because this is a static website, no installation or build process is required.

Simply open:

```text
index.html
```

in your browser.

Alternatively, use a local development server such as VS Code Live Server.
